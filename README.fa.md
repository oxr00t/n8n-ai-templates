# مجموعه ورکفلوهای پیشرفته اتوماسیون هوش مصنوعی و مارکتینگ بر بستر n8n

این ریپازیتوری شامل مجموعه‌ای از ورکفلوهای تولیدی (Production-Ready) و پیشرفته در ابزار اتوماسیون **n8n** است که فرآیندهای مدیریت لید، غنی‌سازی داده‌ها، چت‌بات‌های مجهز به حافظه توزیع‌شده و سیستم‌های هوشمند ایمیل مارکتینگ را با استفاده از هوش مصنوعی پیاده‌سازی می‌کند.

---

## 🚀 ورکفلوهای اصلی

### ۱. سیستم هوشمند جذب و غنی‌سازی لید (Lead Magnet to Voice Agent)
این ورکفلو یک خط لوله (Pipeline) کامل برای تبدیل یک لید خام به یک تماس صوتی هوشمند است.
* **مکانیزم عملکرد:** اعتبارسنجی داده‌های ورودی -> اسکرپ خودکار وب‌سایت لید -> پردازش متن و ساخت دانش‌نامه اختصاصی با OpenAI -> ساخت آنی یک ایجنت صوتی سفارشی در پلتفرم Vapi -> برقراری تماس صوتی خودکار جهت پیگیری لید.

### ۲. چت‌بات هوشمند سازمانی با حافظه دیتابیس (Enterprise Chatbot with Redis Memory)
یک دستیار متنی فوق‌العاده منسجم برای کسب‌وکارهای آموزشی/مشاوره‌ای که بر پایه معماری ایجنت‌های LangChain طراحی شده است.
* **مکانیزم عملکرد:** دریافت پیام از طریق Webhook -> مدیریت حافظه و سشن‌های گفتگو با **Redis Chat Memory** (برای حفظ تاریخچه چت به صورت پایدار و مقیاس‌پذیر) -> استفاده از ابزارها (Tools) برای خواندن مستندات شرکت و ثبت خودکار اطلاعات مشتریان در **Airtable**.

### ۳. اتوماسیون هوشمند ایمیل مارکتینگ و فرآیند پیگیری (AI-Driven Email Marketing & Nurturing)
این ورکفلو زنجیره ارتباطی با مشتری را کامل می‌کند و فرآیند تعامل (Engagement) و ارسال ایمیل‌های شخصی‌سازی‌شده را بر عهده دارد.
* **مکانیزم عملکرد:** گوش به زنگ بودن برای تغییر وضعیت لیدها (تغییر در Airtable/CRM) -> تحلیل رفتار یا فیلدهای کاربر توسط هوش مصنوعی -> تولید خودکار متن ایمیل کاملاً شخصی‌سازی‌شده متناسب با نیاز مشتری -> ارسال خودکار از طریق سرویس‌های ایمیل مارکتینگ (مانند Mailchimp / HubSpot / SES) و به‌روزرسانی وضعیت در دیتابیس.

---

## ⚠️ هشدار بسیار مهم برای راه‌اندازی (Prerequisites & Credentials)

**خیلی مهم:** فایل‌های JSON موجود در این ریپازیتوری فاقد هرگونه کلید امنیتی (API Key) یا اطلاعات احراز هویت هستند. برای اینکه ورکفلوها پس از Import کردن بدون خطا کار کنند، **باید تک‌تک نودها را باز کرده و Credentials و اطلاعات اختصاصی خود را در آن‌ها ست کنید.** n8n بدون تعریف مجدد این اتصالات، ورکفلوها را نخواهد شناخت.

شما به حساب‌ها و کلیدهای دسترسی زیر نیاز خواهید داشت:
* **OpenAI API Key** (برای مدل‌های زبان gpt-4o-mini و ایجنت‌ها)
* **Redis Connection** (اطلاعات سرور Redis خودتان برای بخش Chat Memory)
* **Airtable Personal Access Token** (آی‌دی بیس و جدول‌های خود را جایگزین کنید)
* **Vapi API Key** (برای بخش تماس‌های صوتی هوشمند)
* **Email Service Credentials** (اتصال به سرویس ایمیل شما مانند Gmail/SMTP، Mailchimp یا پلتفرم‌های CRM مشابه جهت نودهای ایمیل مارکتینگ)

## 🛠 نحوه استفاده

1. فایل `.json` ورکفلو مورد نظر را از این ریپازیتوری دانلود کنید.
2. وارد محیط n8n خود شوید و یک ورکفلو جدید بسازید.
3. از منوی بالا سمت راست، گزینه **Import from File** را انتخاب کرده و فایل JSON را آپلود کنید (یا کل متن را کپی و در صفحه n8n پیست کنید).
4. **توجه:** حتماً نودهای وب‌هوک، OpenAI، ایرتیبل، ردیس و سرویس‌های ایمیل/CRM را باز کرده و حساب کاربری (Credentials) خود را به آن‌ها متصل کنید.
5. ورکفلو را فعال (Active) کنید.
